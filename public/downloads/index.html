B Tools

Your private browser utility toolbox. The extension below is a public client package — it performs on-page automation, but holds no credentials and cannot open the authenticated B Tools app on its own.

B Tools Extension

Manifest V3, works in Chrome/Chromium. Replaces the old Tampermonkey-based Auto-Type / Auto-Fill scripts with real extension APIs.

Download extension (.zip)

What's public vs. private here

  • Public client package — this extension. Anyone can download and install it. It contains no secrets and cannot authenticate you.
  • Authenticated B Tools service — the actual tool suite at /.../tools/, behind server-verified login. The extension is a companion to it, not a replacement for it.
  • Install — unzip, then in Chrome go to chrome://extensions, enable Developer mode, and "Load unpacked" the folder.
